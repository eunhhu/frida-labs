flab — cross-game Frida workspace tool

commands:
  flab targets [--json]
      List registered targets (name, process, mode, entry).
  flab new <name> ["Game.exe"] [--proc "Game.exe"] [--json]
      Scaffold a new target and register it in frida-labs.json.
  flab build <target> [--out file]
      Compile a target's agent bundle without injecting.
  flab run <target> [--proc P] [--spawn] [--eval "code"] [--no-watch] [--json]
      Compile, attach, inject, then REPL (or one-shot --eval). Hot reload on save.
  flab probe <process> [--eval "code"] [--json]
      Inject the engine-agnostic probe agent into any process and report what it sees.
